# Prompts Operacionais da Agencia

## 1. Discovery de Cliente

```text
Use business-analyst + research + brand-voice.
Faça o discovery completo deste cliente.
Entregue:
- resumo do negocio
- ICP
- dores, desejos e objecoes
- analise de concorrentes
- oportunidades de posicionamento
- voz da marca
- canais prioritarios para 90 dias
```

## 2. Plano de Campanha

```text
Use orchestrator para coordenar marketing-ideas, copywriter, web-design-expert e content-creation.
Monte uma campanha para [produto/servico].
Entregue:
- grande ideia
- promessa principal
- angulos secundarios
- CTA
- canais recomendados
- pecas necessarias
- cronograma inicial
```

## 3. Landing Page

```text
Use copywriter + web-design-expert.
Crie a estrutura de uma landing page para [oferta].
Inclua:
- headline
- subheadline
- secoes de beneficio
- prova social
- FAQ
- CTA principal
- direcao visual
```

## 4. Calendario Editorial

```text
Use research + hook + content-creation + social-media-generator.
Monte um calendario editorial de 30 dias para [marca] com foco em [objetivo].
Quero:
- pilares editoriais
- 12 a 20 ideias
- formato ideal por canal
- hook de cada peca
- CTA sugerido
```

## 5. Reaproveitamento de Conteudo

```text
Use youtube-content + content-creation + social-media-generator.
Transforme este conteudo central em ativos multiplataforma.
Entregue:
- resumo executivo
- artigo
- thread
- carrossel
- 5 cortes curtos
- email ou newsletter
Link: [cole aqui]
```

## 6. Criativos de Campanha

```text
Use web-design-expert + imagegen.
Crie a direcao visual de uma campanha para [produto].
Entregue:
- conceito criativo
- paleta
- tipografia
- estilo de imagem
- 3 linhas de criativo
- prompts prontos para geracao
```

## 7. Roteiro de Video

```text
Use script-writer + storyboard-creation + sora.
Crie um video promocional para [produto/servico].
Entregue:
- roteiro
- storyboard
- narracao
- sugestao de cenas
- prompt de video
```

## 8. Social Media Semanal

```text
Use social-media-generator + projeto-hive.
Crie 7 posts para [canal] sobre [tema].
Para cada post, quero:
- objetivo
- legenda
- hook
- CTA
- ideia de criativo
```

## 9. Proposta Comercial

```text
Use copywriter + good-prose.
Com base neste briefing, escreva uma proposta comercial clara e objetiva.
Inclua:
- contexto
- objetivo do trabalho
- escopo
- entregaveis
- cronograma
- investimento
- proximos passos
```

## 10. Relatorio Mensal

```text
Use business-intelligence + good-prose.
Transforme estes dados em um relatorio mensal para o cliente.
Inclua:
- resumo executivo
- principais resultados
- leitura dos numeros
- gargalos
- recomendacoes
- plano para o proximo ciclo
```
